## 大输入的吞吐

fuel 不设限，参数是固定种子打乱的 0…n−1，两边用同一份。"原生 Go"是同一件事的 Go 循环，在 100 万个元素上测：筛选求和不建中间数组；排序用 `slices.Sort`，std 的 `sort` 在没有 0 与 -0 这种相等却可区分的元素时也用它。

| 程序 | n = 1 万 | n = 10 万 | n = 100 万 | 每个元素 | 原生 Go 每个元素 | 倍数 |
|---|---|---|---|---|---|---|
| `[x + 1 for x in xs]` | 64.1 µs | 620.9 µs | 6.4 ms | 6.4 ns | 0.31 ns | 21× |
| `sum([x * 2 for x in xs if x % 3 == 0])` | 136.3 µs | 1.3 ms | 13.5 ms | 13.5 ns | 2.42 ns | 5.6× |
| `{string(x): x for x in xs}` | 382.9 µs | 5.0 ms | 108.5 ms | 108.5 ns | 85.31 ns | 1.3× |
| `sort(xs)` | 307.7 µs | 4.6 ms | 53.7 ms | 53.7 ns | 53.70 ns | 1.0× |
| `sum(xs)` | 7.8 µs | 71.9 µs | 477.7 µs | 0.5 ns | 0.26 ns | 1.9× |
| 1000 × 1000 的嵌套推导式 | — | — | 7.8 ms（100 万对） | 7.8 ns / 对 | 0.30 ns / 对 | 26× |

## 编译

`[a * 0 + b, a * 1 + b, …]`：很多重载调用共用同一对参数。

| 项数 | 源码 | 有契约 | 无契约（全部推导） |
|---|---|---|---|
| 100 | 1.2 KB | 1.2 ms | 3.1 ms |
| 500 | 6.2 KB | 6.2 ms | 37.1 ms |
| 1000 | 12.6 KB | 12.6 ms | 135.6 ms |
| 1900 | 24.9 KB | 23.2 ms | 487.6 ms |

`x0 + x1 + …`，变量互不相同，无契约：

| 项数 | 编译 |
|---|---|
| 10 | 87.0 µs |
| 100 | 864.3 µs |
| 1000 | 10.4 ms |
