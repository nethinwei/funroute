## 大输入的吞吐

fuel 不设限，参数是固定种子打乱的 0…n−1，两边用同一份。"原生 Go"是同一件事的 Go 循环，在 100 万个元素上测：筛选求和不建中间数组；排序用 `slices.Sort`，std 的 `sort` 在没有 0 与 -0 这种相等却可区分的元素时也用它。

| 程序 | n = 1 万 | n = 10 万 | n = 100 万 | 每个元素 | 原生 Go 每个元素 | 倍数 |
|---|---|---|---|---|---|---|
| `[x + 1 for x in xs]` | 12.2 µs | 135.1 µs | 1.2 ms | 1.2 ns | 0.28 ns | 4.3× |
| `sum([x * 2 for x in xs if x % 3 == 0])` | 49.5 µs | 460.8 µs | 4.2 ms | 4.2 ns | 2.42 ns | 1.7× |
| `{string(x): x for x in xs}` | 374.3 µs | 4.3 ms | 107.2 ms | 107.2 ns | 83.82 ns | 1.3× |
| `sort(xs)` | 387.6 µs | 4.5 ms | 53.4 ms | 53.4 ns | 53.62 ns | 1.0× |
| `sum(xs)` | 7.5 µs | 71.0 µs | 473.8 µs | 0.5 ns | 0.25 ns | 1.9× |
| 1000 × 1000 的嵌套推导式 | — | — | 1.3 ms（100 万对） | 1.3 ns / 对 | 0.30 ns / 对 | 4.2× |

## 编译

`[a * 0 + b, a * 1 + b, …]`：很多重载调用共用同一对参数。

| 项数 | 源码 | 有契约 | 无契约（全部推导） |
|---|---|---|---|
| 100 | 1.2 KB | 1.3 ms | 3.0 ms |
| 500 | 6.2 KB | 6.2 ms | 36.8 ms |
| 1000 | 12.6 KB | 12.5 ms | 135.2 ms |
| 1900 | 24.9 KB | 23.3 ms | 487.2 ms |

`x0 + x1 + …`，变量互不相同，无契约：

| 项数 | 编译 |
|---|---|
| 10 | 83.5 µs |
| 100 | 829.2 µs |
| 1000 | 10.1 ms |
